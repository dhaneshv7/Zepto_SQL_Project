This project focuses on **business data analysis using SQL**, based on a dataset inspired by **Zepto**, a quick-commerce platform. The objective of the project is to demonstrate how SQL can be effectively used for **data exploration, data cleaning, and analytical problem-solving** in a real-world business context.

The project begins with **data exploration**, where the structure of the dataset is examined to understand key attributes such as products, pricing, categories, availability, and discounts. This step helps identify patterns, inconsistencies, and potential business insights. Next, **data cleaning** is performed to handle missing values, remove duplicates, standardize data formats, and ensure overall data quality, which is essential for accurate analysis.

Once the data is prepared, **SQL-based data analysis** is conducted to answer important business questions. These include analyzing product availability, identifying pricing trends, evaluating discounts, understanding category-wise performance, and extracting insights that could support decision-making. Various SQL concepts such as filtering, aggregation, joins, subqueries, and sorting are used throughout the project.

Overall, this project showcases practical SQL skills applied to business data and serves as a strong example of how structured queries can be used to clean, explore, and analyze data efficiently. It is ideal for learning and demonstrating SQL proficiency in a business analytics setting.
